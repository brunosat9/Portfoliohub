# Estrutura do Repositório

Este documento descreve o planejamento do repositório **Portfoliohub**, criado para organizar projetos acadêmicos e pessoais de forma clara, versionada e pública.

## Planejamento

O repositório foi estruturado para atender a quatro objetivos principais:

1. Apresentar o portfólio profissional digital.
2. Registrar projetos acadêmicos desenvolvidos durante a formação.
3. Demonstrar boas práticas de documentação e organização.
4. Facilitar o compartilhamento com professores, colegas e profissionais do mercado.

## Estrutura planejada

```text
Portfoliohub/
├── index.html
├── README.md
├── documentacao/
├── projetos/
└── apresentacao/
```

## Finalidade das pastas

| Pasta/arquivo | Finalidade |
|---|---|
| `index.html` | Página principal do portfólio publicada no GitHub Pages. |
| `README.md` | Documentação principal do repositório. |
| `documentacao/` | Registro da estrutura, planejamento e práticas de versionamento. |
| `projetos/` | Organização dos projetos acadêmicos e pessoais. |
| `apresentacao/` | Roteiro para apresentação em vídeo sobre o repositório. |

## Critério de organização

Cada projeto deve possuir uma pasta própria e, sempre que possível, um arquivo `README.md` explicando objetivo, tecnologias utilizadas e funcionamento.
