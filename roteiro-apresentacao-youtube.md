# Roteiro para apresentação de 5 minutos - portfolioHUB

## 0:00 - 0:30 | Apresentação inicial

Olá, meu nome é Bruno Soares, sou estudante de Ciências de Dados e Machine Learning no CEUB. Nesta apresentação, vou mostrar o meu repositório portfolioHUB, criado para organizar meus projetos acadêmicos e pessoais com versionamento no GitHub.

## 0:30 - 1:10 | Objetivo do repositório

O objetivo do repositório é reunir meus principais projetos, documentações e materiais profissionais em um espaço público e organizado. Além disso, ele funciona como base para o meu portfólio digital publicado no GitHub Pages.

## 1:10 - 2:00 | Estrutura do repositório

A estrutura foi organizada em seções. Na raiz, está o arquivo `index.html`, que representa o site do portfólio. Também existe o `README.md`, que explica o objetivo do repositório, os links principais, a estrutura de pastas e as tecnologias utilizadas. Além disso, criei pastas para documentação, projetos e apresentação.

## 2:00 - 3:10 | Projetos principais

Dentro da pasta de projetos, organizei três áreas principais. A primeira é o próprio portfolioHUB, que apresenta minha trajetória acadêmica, projetos e formas de contato. A segunda é um projeto de lógica em Python, usado para demonstrar conceitos como listas, laços, soma e média. A terceira é um projeto de banco de dados para farmácia, com exemplo de modelagem SQL utilizando chaves primárias e estrangeiras.

## 3:10 - 4:00 | Versionamento e documentação

O repositório utiliza GitHub para registrar alterações por meio de commits. A documentação foi criada em arquivos Markdown, com explicações sobre a estrutura do repositório e o plano de versionamento. Essa organização facilita a manutenção, o acompanhamento da evolução do projeto e o compartilhamento com outras pessoas.

## 4:00 - 4:40 | GitHub Pages e LinkedIn

O site do portfólio foi publicado por meio do GitHub Pages, permitindo que o conteúdo seja acessado por um link público. O repositório também pode ser integrado ao LinkedIn, adicionando o projeto à seção de destaque ou à seção de projetos do perfil profissional.

## 4:40 - 5:00 | Encerramento

Com essa entrega, o repositório passa a funcionar como uma base profissional para acompanhar minha evolução na área de dados, programação, banco de dados e projetos acadêmicos. Obrigado pela atenção.
