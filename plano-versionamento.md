# Plano de Versionamento

Este documento apresenta as práticas de versionamento adotadas no repositório **Portfoliohub**.

## Objetivo

Registrar a evolução dos arquivos do projeto, permitindo acompanhar alterações, correções e melhorias realizadas no portfólio digital e nos projetos acadêmicos.

## Estratégia de versionamento

O repositório utiliza a branch principal `main` como base para a publicação no GitHub Pages. As alterações importantes devem ser registradas por meio de commits com mensagens claras.

## Exemplos de mensagens de commit

```text
Adicionar página inicial do portfolioHUB
Corrigir informações de contato
Adicionar README principal
Organizar documentação do repositório
Adicionar projeto de lógica em Python
Adicionar modelo SQL de farmácia
Preparar roteiro de apresentação
```

## Histórico sugerido

| Versão | Alteração principal |
|---|---|
| 1.0 | Criação do projeto inicial com a página web. |
| 1.1 | Ajustes de conteúdo, recomendações e links. |
| 1.2 | Organização do repositório com README e pastas. |
| 1.3 | Inclusão de projetos acadêmicos e documentação. |
| 1.4 | Preparação para compartilhamento no LinkedIn e apresentação. |

## Boas práticas adotadas

- Manter nomes de arquivos claros e sem espaços.
- Registrar mudanças por meio de commits objetivos.
- Documentar cada projeto com README próprio.
- Publicar a versão principal do site pelo GitHub Pages.
- Utilizar links públicos para facilitar o compartilhamento profissional.
