# Projeto: Lógica de Programação em Python

## Descrição

Projeto acadêmico com exemplo de programa em Python para exercitar entrada de dados, listas, laços de repetição, cálculo de soma, média e contagens condicionais.

## Objetivo

Demonstrar conhecimentos iniciais de lógica de programação, manipulação de listas e resolução de problemas com Python.

## Arquivo principal

- `media_notas.py`

## Como executar

Abra o arquivo em um ambiente Python, como Spyder, VS Code ou terminal, e execute o programa.

## Conceitos utilizados

- Entrada de dados com `input()`
- Conversão para `float`
- Estrutura de repetição `while`
- Lista de valores
- Soma e média
- Contagem com condições
